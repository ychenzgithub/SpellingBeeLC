# 2027 Spelling Bee Practice (`SpellingBeeLC`)

Interactive standalone web application for practicing the **2027 School Competition List (400 Words)** in Standard American English (`en-US`).

## Features
- **400 Competition Words**: Complete list (`#1. wind` – `#400. Borinqueño`) with parts of speech, definitions, and official alternate spellings.
- **Audio Pronunciation & Definitions**: Automatically pronounces each randomly selected word and reads its definition aloud in Standard American English (`en-US`).
- **3-Try Practice Mode**: Allows up to 3 attempts per word with helpful clues, or instant answer reveal.
- **Searchable Word List**: Click **Show List (400 Words)** to browse, search, listen to, or jump to any word in the list.
- **Standalone HTML**: Open `index.html` directly in any browser with zero server setup required.
